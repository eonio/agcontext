### Added

- Initial release of `@eonio/agcontext` — Augmented Context, a context
  engineering harness for AI coding agents:
  - Code graph engine over TypeScript/JavaScript ASTs (files, classes,
    interfaces, functions, methods, types, enums, variables; imports, exports,
    references, calls, inheritance, composition, containment).
  - Hybrid retrieval: BM25 lexical search, embedding-based semantic search,
    exact-name graph seeding, and budget-guarded best-first graph expansion.
  - Multi-signal ranking (semantic, lexical, graph proximity, PageRank
    centrality, file importance, git activity, recency, dependency weight,
    symbol usage) with weighted and RRF fusion.
  - Repomix-inspired compression: file, symbol, architecture, and dependency
    summaries.
  - Token-aware, deterministic context assembly with markdown/XML/JSON
    renderers and graph-driven recommendations.
  - Provider abstraction: OpenAI, Anthropic, Azure OpenAI, Google Gemini,
    OpenRouter, and an offline deterministic local embedding provider.
  - `agc` CLI: init, index, graph, search, retrieve, context, explain,
    doctor, stats, version.
  - Incremental indexing with persistent caches, opt-in local telemetry, and
    a plugin system (graph, ranking, compression, provider extensions).
